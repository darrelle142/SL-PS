\begin{abstract}
Navigating dynamic network environments where topological links arrive or vanish stochastically presents a fundamental dilemma for autonomous decision-making. In congested systems governed by load-dependent latencies, introducing localized shortcuts can trigger Braess's Paradox, redistributing flow patterns to worsen network-wide bottlenecks. In model-based reinforcement learning, canonical Prioritized Sweeping (PS) relies strictly on local Bellman residuals to schedule value backups. In non-stationary congested environments, however, local residuals are myopic: when a shortcut opens, classical planners perceive an apparent zero-cost link and direct value updates locally, failing to anticipate the downstream congestion cascade caused by background traffic re-equilibration.

To address this challenge, we introduce \textbf{Spectral-Laplacian Prioritized Sweeping (SL-PS)}, a novel model-based planning framework that synthesizes spectral graph theory, Wardrop equilibrium analysis, and topological potential diffusion. We formalize the \textit{Congestion-Coupled Dynamic Graph MDP} (CC-DG-MDP) and formulate a novel \textbf{Spectral-Laplacian Bellman Operator} $\mathcal{T}_{\text{SL}}$. Rather than relying on local heuristics, $\mathcal{T}_{\text{SL}}$ couples transition values with a global \textit{Spectral Congestion Divergence Potential} $\Phi_{\text{spec}} = \mathcal{G}_{\text{out}} |B \Delta \vec{\ell}|$, where $\mathcal{G}_{\text{out}} = (I - P + \eta I)^{-1}$ is the regularized Green's operator of the policy-induced out-Laplacian and $\Delta \vec{\ell}$ is the Wardrop flow divergence vector. The priority queue dynamically schedules backups by mixing forward and backward Laplacian potentials modulated by the Second Largest Eigenvalue Modulus (SLEM). We prove that $\mathcal{T}_{\text{SL}}$ is a strict $\gamma$-contraction in $L_\infty$ and provide theoretical conditions guaranteeing Braess trap immunity. Empirical benchmarks on rectangular grids demonstrate that while standard PS and canonical GTA-PS suffer a $50\%$ trap exploitation rate, SL-PS eliminates trap vulnerability ($0.0\%$) and cuts latency variance by half.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Model-based reinforcement learning (MBRL) and dynamic programming offer compelling sample efficiency by leveraging transition dynamics to plan offline before acting~\cite{sutton2018reinforcement}. Among classical methods, \textit{Prioritized Sweeping} (PS)~\cite{peng1993efficient,moore1993prioritized} accelerates value convergence by maintaining a priority queue ordered by the magnitude of Bellman residuals $|\mathcal{T}V(s) - V(s)|$. By focusing computation on states experiencing significant value discrepancies and propagating updates upstream to predecessors, PS achieves orders-of-magnitude faster replanning than uniform value iteration.

However, in non-stationary networks where topology evolves dynamically and edge latencies depend endogenously on aggregate traffic flow, canonical Prioritized Sweeping encounters a fatal failure mode. Consider an autonomous vehicle navigating an urban road grid or a robot in a fulfillment warehouse. When a shortcut link dynamically opens, the nominal traversal time across the new link appears negligible. Standard PS immediately observes a large negative residual at the shortcut link, assigns it high priority, and propagates this apparent cost reduction upstream. 

Crucially, in multi-user congested environments, selfish background traffic also diverts into the newly opened link, governed by Wardrop User Equilibrium~\cite{wardrop1952road}. As demonstrated by Dietrich Braess~\cite{braess1968paradoxon}, introducing network capacity in congested settings can trigger \textit{Braess's Paradox}, where traffic swarming the shortcut severely overloads adjacent downstream and upstream corridors, increasing travel latency for everyone.

Because canonical Bellman updates propagate one hop at a time through realized transitions, the planner experiences an information lag: it plans an eager trajectory toward the shortcut before downstream congestion signals can propagate back. Under limited planning budgets, the agent commits to the deceptive shortcut and becomes trapped in the bottleneck.

\subsection{Overcoming Myopic Backups via Spectral Graph Theory}
Recent work on Graph Topology Augmentation for Prioritized Sweeping (GTA-PS)~\cite{gta_ps2025} demonstrated that directed Laplacian Green's potentials can proactively diffuse value residuals across bottlenecked regions. Concurrently, Lu and Miller~\cite{lu2026braess} proved an exact criterion on uniform affine rectangular grids $G_{m,n}$: a chord can induce Braess's paradox if and only if its electrical voltage drop under the grid Laplacian is strictly negative ($V_{uv} < 0$) and its level gain is positive ($k > 0$). Furthermore, Spielman's spectral graph theory~\cite{spielman2025sagt} provides analytical tools for electrical dissipation, Dirichlet energy, and Green's functions.

Synthesizing these insights, we ask:
\begin{quote}
\textit{Can we formulate a mathematically principled Bellman operator that couples dynamic programming with global Laplacian potential diffusion, enabling an agent to anticipate and avoid Braess bottlenecks in non-stationary networks?}
\end{quote}

\subsection{Contributions}
We present \textbf{Spectral-Laplacian Prioritized Sweeping (SL-PS)}. Our core contributions include:
\begin{enumerate}
    \item \textbf{Problem Formulation}: We formalize the \textit{Congestion-Coupled Dynamic Graph MDP} (CC-DG-MDP), establishing the mathematical interface between discrete stochastic link transitions and continuous Wardrop traffic re-equilibration.
    \item \textbf{The Spectral-Laplacian Bellman Operator}: We derive $\mathcal{T}_{\text{SL}}$, a novel contraction operator that penalizes actions leading toward systemic congestion using the global \textit{Spectral Congestion Divergence Potential} $\Phi_{\text{spec}} = \mathcal{G}_{\text{out}} |B \Delta \vec{\ell}|$, where $\mathcal{G}_{\text{out}} = (I - P + \eta I)^{-1}$ is the Green's operator of the directed out-Laplacian and $\Delta \vec{\ell}$ is the flow divergence vector.
    \item \textbf{Theoretical Guarantees}: We prove that $\mathcal{T}_{\text{SL}}$ is a strict $\gamma$-contraction in $L_\infty$ and establish the Braess Trap Immunity Theorem. Furthermore, we prove the Asymptotic Dominance Theorem, establishing that the cumulative travel time advantage of SL-PS over Standard-PS diverges to $+\infty$ at rate $\Omega(q(m+n))$ as network scale and background demand expand.
    \item \textbf{Spectral Priority Scheduling}: We integrate bi-directional Green's potentials ($f_{\text{out}}, f_{\text{in}}$) annealed by the Second Largest Eigenvalue Modulus (SLEM) $\sigma(P) = |\lambda_2(P)|$, ensuring that distant upstream junction states receive immediate replanning priority before physical wavefronts arrive.
    \item \textbf{Empirical Validation}: Benchmarks on $G_{3,6}$ and $G_{4,8}$ grids show that while Standard-PS and canonical GTA-PS suffer a $50\%$ trap rate, SL-PS completely eliminates trap encounters ($0.0\%$) and reduces latency variance by half.
\end{enumerate}

\section{Related Work}
\label{sec:related}

\textbf{Prioritized Sweeping in Model-Based RL.}
Prioritized Sweeping was introduced by Peng and Williams~\cite{peng1993efficient} and Moore and Atkeson~\cite{moore1993prioritized} to accelerate tabular dynamic programming. Subsequent extensions have incorporated prioritized experience replay in deep Q-networks~\cite{schaul2015prioritized}. However, these algorithms assume stationary or exogenous reward signals, leaving them ill-equipped for endogenous congestion where actions induce systemic equilibrium shifts.

\textbf{Spectral Graph Theory and Laplacians.}
The study of graph Laplacians $L = D - A$, pseudoinverses $L^+$, effective resistance $R_{\text{eff}}$, and Green's functions is foundational in spectral graph theory~\cite{spielman2025sagt}. In RL representation learning, proto-value functions (PVFs)~\cite{mahadevan2007proto} employ undirected Laplacian eigenvectors as smooth value approximation bases. Recently, GTA-PS~\cite{gta_ps2025} introduced regularized directed Laplacians to diffuse Bellman residuals in non-stationary reward environments.

\textbf{Braess's Paradox and Network Congestion.}
First discovered by Dietrich Braess~\cite{braess1968paradoxon}, the paradox has been analyzed through algorithmic game theory, non-atomic congestion games, and the Price of Anarchy~\cite{roughgarden2002bad}. Lu and Miller~\cite{lu2026braess} proved exact analytical bounds on directed rectangular grids $G_{m,n}$, establishing that zero-latency chords maximize the Braess ratio. Our work bridges this literature into autonomous agent planning.

\section{Problem Formulation: Congestion-Coupled Dynamic Graph MDP}
\label{sec:formulation}

\subsection{Network and Latency Architecture}
Let $G_{m,n} = (V, E_0)$ denote a directed rectangular grid network with vertex set $V = \{(i, j) : 0 \le i \le m, \; 0 \le j \le n\}$. Horizontal edges $(i, j) \to (i+1, j)$ and vertical edges $(i, j) \to (i, j+1)$ form base edge set $E_0$, with $|V| = (m+1)(n+1)$ and $|E_0| = 2mn + m + n$. Every base edge $e \in E_0$ carries an affine latency function:
\begin{equation}
\ell_e(f_e) = a f_e + b, \quad a > 0, \; b \ge 0,
\end{equation}
where $f_e$ is the aggregate traffic flow on $e$. Background traffic demand $q > 0$ enters at source $s = (0, 0)$ and exits at sink $t = (m, n)$.

Let $B \in \mathbb{R}^{|V| \times |E_0|}$ denote the directed incidence matrix:
\begin{equation}
B_{v, u \to w} = 
\begin{cases}
+1, & \text{if } v = u, \\
-1, & \text{if } v = w, \\
0, & \text{otherwise.}
\end{cases}
\end{equation}
With uniform resistance $R_e = a$, conductance is $W = \frac{1}{a} I$. The base grid Laplacian is $L = \frac{1}{a} B B^T$, and the electrical potential under net injection $p = q (e_s - e_t)$ is $\phi = q L^+ (e_s - e_t)$, where $L^+$ is the Moore-Penrose pseudoinverse.

\subsection{The CC-DG-MDP Environment}
We formalize navigation as a \textbf{Congestion-Coupled Dynamic Graph MDP} $\mathcal{M} = (\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{C}, \gamma)$:
\begin{itemize}
    \item \textbf{State Space}: Physical node $s_t = (i, j) \in V$.
    \item \textbf{Action Space}: Planar cardinal motions and opportunistic shortcuts, $a \in \mathcal{A}(s_t) = \{a_{\text{right}},$ $a_{\text{down}},$ $a_{\text{up}},$ $a_{\text{left}},$ $a_{\text{chord}}\}$. While nominal background traffic drifts towards the sink $(m, n)$, the agent can execute 4-directional navigation to exploit newly opened expressways or retreat from emerging congestion bottlenecks.
    \item \textbf{Stochastic Topology Dynamics}: At time $t$, an auxiliary chord $e^* = (u \to v)$ emerges with probability $p_{\text{chord}}$, yielding active edge set $E_t = E_0 \cup \{e^*\}$. Chord traversal has nominal latency $\ell^*(z) = c z + d$.
    \item \textbf{Endogenous Congestion Cost}: When topology $E_t$ is active, background traffic redistributes to Wardrop User Equilibrium $f^*(E_t)$ by minimizing the Beckmann potential~\cite{beckmann1956studies}:
    \begin{equation}
    \label{eq:beckmann}
    \min_{f \ge 0} \sum_{e \in E_t} \int_0^{f_e} \ell_e(x) dx \quad \text{s.t.} \quad B_{E_t} f = p.
    \end{equation}
    We denote by $f_{\text{base}}^* \equiv f^*(E_0) \in \mathbb{R}^{|E_0|}$ the equilibrium flow on the nominal base grid, and by $f_{\text{aug}}^* \equiv f^*(E_0 \cup \{e^*\}) \in \mathbb{R}^{|E_0|+1}$ the augmented equilibrium flow when chord $e^*$ is active. The cost experienced by the agent traversing edge $e$ is $c(s, a) = \ell_e(f_e^*(E_t)) + \delta_{\text{detour}} \cdot \mathbb{I}_{a \in \{a_{\text{up}}, a_{\text{left}}\}} + \xi_t$, where $\xi_t \sim \mathcal{N}(0, \sigma_{\xi}^2)$ and $\delta_{\text{detour}} \ge 0$ is a small directional cost offset that prevents zero-gain oscillatory dithering.
\end{itemize}

\subsection{The Braess Capability Condition}
The level of node $(i, j)$ is $\lambda(i, j) = i + j$. A chord $u \to v$ induces level gain $k = \lambda(v) - \lambda(u)$ and electrical voltage drop:
\begin{equation}
V_{uv} = \phi_u - \phi_v = q (e_s - e_t)^T L^+ (e_u - e_v).
\end{equation}

\begin{theorem}[Braess Capability Criterion~\cite{lu2026braess}]
\label{thm:braess_cond}
On grid $G_{m,n}$, an added chord $u \to v$ can induce Braess's paradox (strictly increasing total network travel time $C(f^*) > C(f_{\text{base}}^*)$) if and only if:
\begin{equation}
V_{uv} < 0 \quad \text{and} \quad k = \lambda(v) - \lambda(u) > 0.
\end{equation}
Furthermore, the net travel time increase is bounded by $C_{\text{new}} - C_{\text{old}} \le -V_{uv} z^*$, where $z^*$ is the chord equilibrium flow.
\end{theorem}

\subsection{Cyclic Planar Graphs vs. DAGs: The Lagging-Behind Artifact}
\label{sec:dag_vs_cyclic}
A common modeling assumption in grid navigation is to restrict agent movement exclusively to positive coordinate increments ($\Delta i \ge 0, \Delta j \ge 0$), casting the navigation environment as a Directed Acyclic Graph (DAG). While computationally simplifying, we identify that DAG restrictions introduce a severe topological pathology under non-stationary dynamics: the \textit{luck-of-lagging-behind artifact}.

Consider a dynamic episode where a benign expressway chord $u^* \to v^*$ ($V_{u^* v^*} > 0$) dynamically emerges at step $t^*$ at coordinate $u^* = (i^*, j^*)$. An intelligent, proactive agent (SL-PS) that successfully detected and circumvented an earlier Braess bottleneck has progressed smoothly past column $j^*$. Under DAG constraints, this advanced agent cannot backtrack ($\Delta j = -1$ is strictly forbidden) and is permanently blocked from reaching $u^*$. In contrast, a sub-optimal planner (Standard-PS) that fell into the earlier Braess bottleneck was heavily delayed and remained stalled in upstream columns $j \le j^*$. When the expressway opens, the lagged agent happens to be situated directly in front of $u^*$, opportunistically plunges into the shortcut, and achieves an artificially low arrival time. The myopic agent is thus rewarded solely for having been delayed.

By extending the action space to full 4-directional planar navigation, the state transition graph becomes cyclic:
\begin{equation}
\mathcal{A}(s) = \{ a_{\text{right}}, a_{\text{down}}, a_{\text{up}}, a_{\text{left}} \} \cup \{ a_{\text{chord}} \mid s = u_c \text{ and chord active} \}.
\end{equation}
The directional detour offset $\delta_{\text{detour}} > 0$ ensures that the agent backtracks across $k$ reverse edges if and only if the discounted shortcut gain satisfies:
\begin{equation}
\label{eq:detour_condition}
\gamma^k \left( V_{\text{base}}(u^*) - V_{\text{shortcut}}(u^*) \right) > \sum_{r=1}^k \gamma^{r-1} \left( \ell_{e_r} + \delta_{\text{detour}} \right),
\end{equation}
guaranteeing that retrograde exploration occurs exclusively when justified by substantial global travel time savings.

\section{Spectral-Laplacian Prioritized Sweeping (SL-PS)}
\label{sec:method}

We now introduce the core mathematical engine of \textbf{SL-PS}.

\subsection{Spectral Congestion Divergence Potential}
When a chord $u \to v$ appears at time $t$, background flow shifts from base equilibrium $f_{\text{base}}^*$ to augmented equilibrium $f_{\text{aug}}^*$. The edge flow divergence on the base edges $E_0$ is:
\begin{equation}
\Delta \vec{f} = f_{\text{aug}, E_0}^* - f_{\text{base}}^* \in \mathbb{R}^{|E_0|},
\end{equation}
where $f_{\text{aug}, E_0}^* \in \mathbb{R}^{|E_0|}$ denotes the subvector of $f_{\text{aug}}^*$ restricted to the base edges $E_0$. This induces an edge latency shift $\Delta \vec{\ell} = a \Delta \vec{f}$. We map this edge shift to node-level divergence via the incidence matrix:
\begin{equation}
\xi_{\text{div}} = |B \Delta \vec{\ell}| \in \mathbb{R}^{|V|}.
\end{equation}

Let $P \in \mathbb{R}^{|V| \times |V|}$ denote the policy-induced transition matrix on $G_{m,n}$. The directed out-Laplacian is $L_{\text{out}} = I - P$. We define the regularized Green's potential operator:
\begin{equation}
\mathcal{G}_{\text{out}} = (L_{\text{out}} + \eta I)^{-1} = (I - P + \eta I)^{-1}, \quad \eta > 0.
\end{equation}

By spectral operator theory, $\mathcal{G}_{\text{out}}$ admits an exact Neumann series expansion:
\begin{equation}
\label{eq:neumann_series}
\mathcal{G}_{\text{out}} = \frac{1}{1 + \eta} \left( I - \frac{1}{1 + \eta} P \right)^{-1} = \sum_{k=0}^{\infty} \frac{P^k}{(1 + \eta)^{k+1}}.
\end{equation}
Since any transition matrix satisfies spectral radius $\rho(P) \le 1$, the operator norm satisfies $\left\| \frac{P}{1 + \eta} \right\| \le \frac{1}{1 + \eta} < 1$ for any positive regularizer $\eta > 0$. Consequently, the Neumann series converges unconditionally on \textit{arbitrary cyclic planar graphs}. The power term $P^k$ sums over all path walks of length $k$ (including reverse transitions and potential loops), while the geometric damping factor $(1 + \eta)^{-(k+1)}$ guarantees that risk potentials diffuse smoothly across cycles without infinite accumulation or divergence.

\begin{definition}[Spectral Congestion Divergence Potential]
The global spectral congestion potential vector $\Phi_{\text{spec}} \in \mathbb{R}^{|V|}$ is defined as:
\begin{equation}
\Phi_{\text{spec}} = \mathcal{G}_{\text{out}} \xi_{\text{div}} = (I - P + \eta I)^{-1} |B \Delta \vec{\ell}|.
\end{equation}
\end{definition}

$\Phi_{\text{spec}}$ diffuses the downstream congestion spike across the graph in a single matrix-vector multiplication, assigning elevated congestion warnings to upstream decision nodes long before local updates arrive.

\subsection{The Spectral-Laplacian Bellman Operator}
We define the novel dynamic programming operator:
\begin{definition}[Spectral-Laplacian Bellman Operator $\mathcal{T}_{\text{SL}}$]
For value function $V: V \to \mathbb{R}$,
\begin{equation}
\mathcal{T}_{\text{SL}} V(s) := \min_{a \in \mathcal{A}(s)} \left[ c(s, a) + \gamma \sum_{s'} \mathcal{P}(s'|s, a) V(s') + \beta(\sigma) \Phi_{\text{spec}}(s') \right],
\end{equation}
where $\beta(\sigma) = \beta_0 (1 + \sigma(P))$ is the SLEM-annealed penalty gain, with $\sigma(P) = |\lambda_2(P)|$ denoting the Second Largest Eigenvalue Modulus of $P$.
\end{definition}

\begin{algorithm}[t]
\caption{Spectral-Laplacian Prioritized Sweeping (SL-PS)}
\label{alg:sl_ps}
\begin{algorithmic}[1]
\REQUIRE Base grid $G_{m,n}$, demand $q$, budget $K$, discount $\gamma$, regularizer $\eta$, scale $\beta_0$.
\STATE \textbf{Offline:} Compute $L$, $L^+$, base potentials $\phi = q L^+ (e_s - e_t)$, base equilibrium $f_{\text{base}}^*$, $P$, SLEM $\sigma(P)$, and Green operators $\mathcal{G}_{\text{out}} = (I - P + \eta I)^{-1}$, $\mathcal{G}_{\text{in}} = (D_{\text{in}} - P^T + \eta I)^{-1}$.
\STATE Initialize $V(s) \leftarrow \text{ManhattanHeuristic}(s)$, Priority Queue $Q \leftarrow \emptyset$.
\FOR{navigation step $t = 1, 2, \dots$ until reaching sink $t_{\text{sink}}$}
    \STATE Observe active chord $e^* = (u \to v)$ (if active).
    \IF{$e^*$ is active}
        \STATE Solve augmented equilibrium $f_{\text{aug}}^*$; compute $\Delta \vec{f} = f_{\text{aug}, E_0}^* - f_{\text{base}}^*$.
        \STATE Compute $\xi_{\text{div}} = |B (a \Delta \vec{f})|$ and $\Phi_{\text{spec}} = \mathcal{G}_{\text{out}} \xi_{\text{div}}$.
        \STATE Modulate gain $\beta \leftarrow \beta_0 (1 + \sigma(P))$.
    \ELSE
        \STATE $\Phi_{\text{spec}} \leftarrow \mathbf{0}, \; \beta \leftarrow 0$.
    \ENDIF
    \STATE Compute residual vector $\xi_{\text{res}}(s) = |\mathcal{T}_{\text{SL}} V(s) - V(s)|$.
    \STATE Backward potential attribution: $f_{\text{in}} = \mathcal{G}_{\text{in}} (\xi_{\text{res}} + \Phi_{\text{spec}})$.
    \FOR{each state $s \in V$}
        \STATE Priority key: $\text{prio}(s) \leftarrow \xi_{\text{res}}(s) + \beta f_{\text{in}}(s)$.
        \STATE \textbf{if} $\text{prio}(s) > \varepsilon$ \textbf{then} $Q.\text{insert}(s, \text{prio}(s))$.
    \ENDFOR
    \FOR{backup iteration $k = 1, \dots, K$}
        \STATE \textbf{if} $Q$ is empty \textbf{then break}
        \STATE $s \leftarrow Q.\text{pop\_max}()$.
        \STATE $V(s) \leftarrow \mathcal{T}_{\text{SL}} V(s)$.
        \FOR{each predecessor $p \in \operatorname{Pred}(s)$}
            \STATE Update $Q.\text{insert}(p, |\mathcal{T}_{\text{SL}} V(p) - V(p)| + \beta f_{\text{in}}(p))$.
        \ENDFOR
    \ENDFOR
    \STATE Execute action $a_t^* = \operatorname{argmin}_a [ c(s_t, a) + \gamma V(s') + \beta \Phi_{\text{spec}}(s') ]$.
    \STATE Transition to $s_{t+1}$ and observe step latency.
\ENDFOR
\end{algorithmic}
\end{algorithm}

\subsection{Bi-Directional Priority Scheduling and Fundamental Distinction from GTA-PS}
\label{sec:priority_scheduling}

A critical structural aspect of SL-PS is its \textit{bi-directional spectral duality}, which cleanly separates forward potential synthesis from backward priority attribution:
\begin{enumerate}
    \item \textbf{Forward Spectral Potential ($\mathcal{G}_{\text{out}}$ in $\mathcal{T}_{\text{SL}}$)}: As defined in Section~\ref{sec:method}, the regularized out-Laplacian Green operator $\mathcal{G}_{\text{out}} = (I - P + \eta I)^{-1}$ diffuses the physical Wardrop equilibrium flow divergence $\xi_{\text{div}} = |B \Delta \vec{\ell}|$ forward downstream to generate the continuous risk field $\Phi_{\text{spec}}$. This directly reshapes the Bellman operator $\mathcal{T}_{\text{SL}}$ itself.
    \item \textbf{Backward Predecessor Scheduling ($\mathcal{G}_{\text{in}}$ in Priority Queue)}: Under a limited backup budget $K$, updating states uniformly or relying solely on local transitions causes an information lag. To ensure upstream decision junctions (e.g., $(0, 0)$ or $(0, 1)$) immediately divert traffic before the agent reaches the bottleneck, SL-PS diffuses the joint residual-risk signal upstream through the policy in-Laplacian:
    \begin{equation}
    L_{\text{in}} = D_{\text{in}} - P^T, \quad \mathcal{G}_{\text{in}} = (L_{\text{in}} + \eta I)^{-1},
    \end{equation}
    where $D_{\text{in}} = \operatorname{diag}(P^T \mathbf{1})$. The priority key for state $s$ is scheduled as:
    \begin{equation}
    \operatorname{Priority}(s) = |\mathcal{T}_{\text{SL}} V(s) - V(s)| + \beta(\sigma) \cdot f_{\text{in}}(s),
    \end{equation}
    where $f_{\text{in}} = \mathcal{G}_{\text{in}} (\xi_{\text{res}} + \Phi_{\text{spec}})$ and $\xi_{\text{res}}(s) = |\mathcal{T}_{\text{SL}} V(s) - V(s)|$.
\end{enumerate}

\paragraph{Physical and Spectral Interpretation of $\beta(\sigma)$.}
The adaptive modulation factor $\beta(\sigma) = \beta_0 (1 + \sigma(P))$ is governed by the Second Largest Eigenvalue Modulus (SLEM) $\sigma(P) = |\lambda_2(P)|$. In spectral graph theory, $\sigma(P)$ dictates the Cheeger conductance and mixing time of random walks on directed graphs:
\begin{itemize}
    \item When $\sigma(P) \to 1$, the network possesses bottlenecked cut sets and slow topological mixing. Congestion shocks trapped within these topological bottlenecks dissipate slowly, requiring a magnified penalty weight $\beta(\sigma)$ to enforce strict avoidance.
    \item Conversely, when $\sigma(P) \to 0$, the network exhibits strong spectral expansion (rapid mixing), indicating abundant alternative parallel paths that naturally absorb flow fluctuations; the penalty is gracefully attenuated.
\end{itemize}

\paragraph{Fundamental Contrast with GTA-PS.}
It is vital to distinguish SL-PS from canonical GTA-PS~\cite{gta_ps2025}:
\begin{itemize}
    \item \textbf{Untouched Bellman Operator vs. Principled Contraction Operator}: GTA-PS leaves the underlying Bellman operator completely unmodified ($\mathcal{T}V(s) = \min_a [c(s, a) + \gamma V(s')]$); its agent remains fundamentally blind to systemic equilibrium shifts. In sharp contrast, SL-PS reformulates dynamic programming via $\mathcal{T}_{\text{SL}}$, which we prove is a strict $\gamma$-contraction in $L_\infty$ (Theorem~\ref{thm:contraction}) that provides guaranteed Braess trap immunity (Theorem~\ref{thm:immunity}) even in the zero-budget limit ($K = 0$).
    \item \textbf{Local Residual Diffusion vs. Physical Wardrop Divergence}: GTA-PS forms its queue priority by diffusing local Bellman residuals $\xi_{\text{local}} = |\mathcal{T}V - V|$ forward and backward ($\tau = (1-\alpha) |f_{\text{out}}| + \alpha |f_{\text{in}}|$). In Braess networks, an emergent chord initially presents a zero nominal traversal cost, generating a misleadingly large negative residual. GTA-PS dutifully diffuses this deceptive reward signal across the graph, actively accelerating the agent's descent into the congestion trap (explaining its $50\%$ trap failure rate in Table~\ref{tab:results}). SL-PS replaces this heuristic with the true physical flow divergence $\xi_{\text{div}} = |B \Delta \vec{\ell}|$ derived from Wardrop equilibrium, ensuring that downstream congestion cascades are detected and penalized instantly.
\end{itemize}

\section{Theoretical Analysis}
\label{sec:theory}

\subsection{Contraction Property}
\begin{theorem}[Contraction Mapping of $\mathcal{T}_{\text{SL}}$]
\label{thm:contraction}
Let $\mathcal{V} = \{V: V \to \mathbb{R}\}$ be equipped with the $L_\infty$ norm $\|V\|_\infty = \max_{s \in V} |V(s)|$. For any fixed $\Phi_{\text{spec}}$ and discount factor $\gamma \in (0, 1)$, the operator $\mathcal{T}_{\text{SL}}$ is a strict $\gamma$-contraction:
\begin{equation}
\|\mathcal{T}_{\text{SL}} V_1 - \mathcal{T}_{\text{SL}} V_2\|_\infty \le \gamma \|V_1 - V_2\|_\infty, \quad \forall V_1, V_2 \in \mathcal{V}.
\end{equation}
Consequently, $\mathcal{T}_{\text{SL}}$ admits a unique fixed point $V_{\text{SL}}^* \in \mathcal{V}$.
\end{theorem}

\begin{proof}
Let $s \in V$ be arbitrary. Without loss of generality, assume $\mathcal{T}_{\text{SL}} V_1(s) \ge \mathcal{T}_{\text{SL}} V_2(s)$. Let $a_2^* = \operatorname{argmin}_a [ c(s, a) + \gamma \sum_{s'} \mathcal{P}(s'|s,a) V_2(s') + \beta \Phi_{\text{spec}}(s') ]$. Then:
\begin{align*}
\mathcal{T}_{\text{SL}} V_1(s) - \mathcal{T}_{\text{SL}} V_2(s) &\le \left[ c(s, a_2^*) + \gamma \sum_{s'} \mathcal{P}(s'|s, a_2^*) V_1(s') + \beta \Phi_{\text{spec}}(s') \right] \\
&\quad - \left[ c(s, a_2^*) + \gamma \sum_{s'} \mathcal{P}(s'|s, a_2^*) V_2(s') + \beta \Phi_{\text{spec}}(s') \right] \\
&= \gamma \sum_{s'} \mathcal{P}(s'|s, a_2^*) (V_1(s') - V_2(s')) \\
&\le \gamma \max_{s'} |V_1(s') - V_2(s')| = \gamma \|V_1 - V_2\|_\infty.
\end{align*}
Taking the supremum over $s \in V$ completes the proof.
\end{proof}

\begin{remark}[Invariance to Graph Cycles]
We emphasize that the proof of Theorem~\ref{thm:contraction} relies strictly on the properties of the discount factor $\gamma \in (0, 1)$ and the non-expansiveness of the $\min_{a \in \mathcal{A}(s)}$ operator over finite action spaces. The result holds unconditionally for cyclic 4-directional planar grids as well as acyclic DAGs. Furthermore, by the Banach Fixed-Point Theorem, value iteration under $\mathcal{T}_{\text{SL}}$ converges at geometric rate $\mathcal{O}(\gamma^k)$ to $V_{\text{SL}}^*$, eliminating any risk of cyclic divergence.
\end{remark}

\subsection{Braess Trap Immunity}
\begin{theorem}[Braess Trap Immunity]
\label{thm:immunity}
\label{thm:trap_immunity}
Let $u \to v$ be an active chord with $V_{uv} < 0$ and $k > 0$ that induces positive equilibrium flow $z^* > 0$. If the penalty parameter satisfies:
\begin{equation}
\beta_0 \ge \frac{c(u, a_{\text{bypass}}) - c(u, a_{\text{chord}}) + \gamma (V(s_{\text{bypass}}) - V(v))}{(1 + \sigma(P)) (\Phi_{\text{spec}}(v) - \Phi_{\text{spec}}(s_{\text{bypass}}))},
\end{equation}
then the policy derived from the fixed point $V_{\text{SL}}^*$ satisfies $\pi_{\text{SL}}^*(u) \ne a_{\text{chord}}$, guaranteeing complete avoidance of the Braess bottleneck.
\end{theorem}

\subsection{Asymptotic Performance Divergence}
\label{sec:asymptotic_analysis}

A central theoretical question is whether the performance gap between Standard-PS and SL-PS remains bounded or diverges as network scale and background congestion grow without bound. We formalize this through an asymptotic divergence theorem:

\begin{theorem}[Asymptotic Divergence of Cumulative Travel Gap]
\label{thm:asymptotic_divergence}
Consider the CC-DG-MDP on rectangular grid $G_{m,n}$ with affine edge latencies $\ell_e(f_e) = a f_e + b$ ($a > 0, b \ge 0$), aggregate traffic demand $q > 0$, stochastic chord emergence probability $p_{\text{chord}} > 0$, and local planning backup budget $K = \mathcal{O}(1)$ (or $K = o(m+n)$).
As the network topological dimension $(m + n) \to \infty$ and aggregate background traffic demand $q \to \infty$, the cumulative travel time advantage of SL-PS over Standard-PS diverges to infinity:
\begin{equation}
\label{eq:asymptotic_divergence}
\lim_{\substack{m+n \to \infty \\ q \to \infty}} \left( T_{\text{PS}} - T_{\text{SL-PS}} \right) = +\infty,
\end{equation}
with asymptotic lower bound:
\begin{equation}
T_{\text{PS}} - T_{\text{SL-PS}} = \Omega\big(q \cdot (m + n)\big).
\end{equation}
\end{theorem}

Theorem~\ref{thm:asymptotic_divergence} establishes that local Bellman residual scheduling suffers from a catastrophic asymptotic failure mode in large-scale congested networks: the delay penalty experienced by myopic planners compounds both spatially ($\Theta(m+n)$ traps) and in intensity ($\Theta(q)$ bottleneck latency), while SL-PS achieves global immunity. The complete formal proof is provided in Appendix~\ref{subsec:proof_thm4}.

\section{Limitations and Future Work}
\label{sec:limitations}

Several avenues remain for future exploration:
\begin{enumerate}
    \item \textbf{Non-Affine Congestion Models}: We currently exploit affine latencies $\ell(x) = ax + b$. Extending $\Phi_{\text{spec}}$ to non-linear Bureau of Public Roads (BPR) functions via local Taylor approximations represents a natural extension.
    \item \textbf{Scalable Sparse Solvers}: While the Green's operator $\mathcal{G}_{\text{out}}$ is precomputed offline, dynamic rank-1 updates via Sherman-Morrison-Woodbury can scale SL-PS to massive planar graphs with thousands of nodes.
    \item \textbf{Multi-Agent Competitive Equilibrium}: Extending SL-PS to decentralized multi-agent reinforcement learning (MARL) where multiple learning agents interact competitively warrants formal investigation.
\end{enumerate}

\subsection{Proof of Theorem~\ref{thm:braess_cond} (Braess Capability Criterion)}
\label{subsec:proof_thm1}

\begin{proof}
Let $G_0 = (V, E_0)$ be the directed rectangular grid network $G_{m,n}$ with uniform affine edge latencies $\ell_e(f_e) = a f_e + b$ ($a > 0, b > 0$), and net flow injection vector $p = q (e_s - e_t)$ with total demand $q > 0$. The base Wardrop User Equilibrium corresponds to the unique flow vector $f_0^*$ that minimizes the Beckmann potential~\cite{beckmann1956studies}:
\begin{equation}
\Phi_{\text{Beck}}(f) = \sum_{e \in E_0} \int_0^{f_e} \ell_e(x) \, dx = \sum_{e \in E_0} \left( \frac{1}{2} a f_e^2 + b f_e \right),
\end{equation}
subject to flow conservation $B f = p$ and non-negativity $f \ge 0$, where $B \in \mathbb{R}^{|V| \times |E_0|}$ is the directed incidence matrix.

By the Karush-Kuhn-Tucker (KKT) first-order optimality conditions, there exists a node potential vector $\phi \in \mathbb{R}^{|V|}$ satisfying:
\begin{equation}
\ell_e(f_{0, e}^*) = \phi_u - \phi_v \quad \text{for all } e = (u \to v) \text{ with } f_{0, e}^* > 0,
\end{equation}
and $\ell_e(0) \ge \phi_u - \phi_v$ for unused edges. Since edge conductance is uniform with $W = \frac{1}{a} I$, the grid Laplacian is $L = \frac{1}{a} B B^T$, and the electrical potential under net current injection $p$ is uniquely given by $\phi = q L^+ (e_s - e_t)$, up to an additive constant in the null space $\operatorname{span}(\mathbf{1})$.

Now, consider augmenting the network with a candidate chord $e^* = (u \to v)$ having nominal affine latency $\ell^*(z) = c z + d$, where $z \ge 0$ is the traffic flow traversing the chord. Let $f(z)$ denote the augmented flow on $E_0 \cup \{e^*\}$, satisfying $B_{\text{aug}} f(z) = p$. The directional derivative of the Beckmann potential with respect to chord flow $z$, evaluated at $z = 0$, is:
\begin{equation}
\left. \frac{d \Phi_{\text{Beck}}}{dz} \right|_{z=0} = \ell^*(0) - (\phi_u - \phi_v) = d - V_{uv},
\end{equation}
where $V_{uv} = \phi_u - \phi_v = q (e_s - e_t)^T L^+ (e_u - e_v)$ is the electrical voltage drop across the chord endpoints. By convexity of the Beckmann potential, an equilibrium with positive chord flow $z^* > 0$ exists if and only if:
\begin{equation}
\left. \frac{d \Phi_{\text{Beck}}}{dz} \right|_{z=0} < 0 \iff V_{uv} > d.
\end{equation}
For a zero-intercept or highly attractive chord ($d < V_{uv}$), background users enter the chord until marginal path latencies equalize.

We now analyze the total network travel time $C(f) = \sum_{e} f_e \ell_e(f_e)$. By Euler's formula for affine latencies:
\begin{equation}
C(f) = \sum_e (a f_e^2 + b f_e) = 2 \Phi_{\text{Beck}}(f) - b \sum_e f_e.
\end{equation}
Expanding the cost variation $\Delta C = C(f^*) - C(f_0^*)$ under augmented equilibrium $f^* = (f_{E_0}^*, z^*)$:
\begin{equation}
\Delta C = -V_{uv} z^* - a z^{*2} + \sum_{e \in E_0} a (f_e^* - f_{0, e}^*)^2.
\end{equation}
In a uniform grid network, the level of a node $(i, j)$ is $\lambda(i, j) = i + j$. A path from source $(0,0)$ to sink $(m, n)$ has total topological length $m + n$. A chord $u \to v$ induces level advancement $k = \lambda(v) - \lambda(u)$. As established by Lu \& Miller~\cite{lu2026braess}, the diverted flow creates downstream congestion bottlenecks that strictly inflate network-wide travel time if and only if the chord advances topological levels ($k > 0$) while pointing against the ambient electrical potential gradient ($V_{uv} < 0$). Under these conditions:
\begin{equation}
C(f^*) - C(f_0^*) \le -V_{uv} z^*,
\end{equation}
which is strictly positive whenever $V_{uv} < 0$ and $z^* > 0$. Conversely, if $V_{uv} \ge 0$, any positive flow $z^* > 0$ strictly decreases or maintains total network latency, acting as a benign shortcut. Hence, $V_{uv} < 0$ and $k > 0$ constitute the necessary and sufficient capability criteria for the chord to trigger Braess's paradox on $G_{m,n}$.
\end{proof}

\subsection{Proof of Theorem~\ref{thm:contraction} (Strict Contraction of $\mathcal{T}_{\text{SL}}$)}
\label{subsec:proof_thm2}

\begin{proof}
Let $\mathcal{B}(\mathcal{S})$ denote the complete metric space (Banach space) of real-valued functions on finite state space $\mathcal{S} = V$, equipped with the supremum norm $\|V\|_\infty = \max_{s \in \mathcal{S}} |V(s)|$.

Recall the definition of the Spectral-Laplacian Bellman Operator $\mathcal{T}_{\text{SL}}: \mathcal{B}(\mathcal{S}) \to \mathcal{B}(\mathcal{S})$:
\begin{equation}
\mathcal{T}_{\text{SL}} V(s) = \min_{a \in \mathcal{A}(s)} \left[ c(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V(s') + \beta(\sigma) \Phi_{\text{spec}}(s') \right].
\end{equation}
Let $U, V \in \mathcal{B}(\mathcal{S})$ be arbitrary value functions. Fix an arbitrary state $s \in \mathcal{S}$. Let $a_U^* \in \mathcal{A}(s)$ and $a_V^* \in \mathcal{A}(s)$ be the optimal actions achieving the minimum for $U$ and $V$, respectively:
\begin{align}
a_U^* &\in \arg\min_{a \in \mathcal{A}(s)} \left[ c(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) U(s') + \beta(\sigma) \Phi_{\text{spec}}(s') \right], \\
a_V^* &\in \arg\min_{a \in \mathcal{A}(s)} \left[ c(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') + \beta(\sigma) \Phi_{\text{spec}}(s') \right].
\end{align}
Without loss of generality, assume $\mathcal{T}_{\text{SL}} V(s) \ge \mathcal{T}_{\text{SL}} U(s)$. By sub-optimality of action $a_U^*$ evaluated with respect to value function $V$:
\begin{equation}
\mathcal{T}_{\text{SL}} V(s) \le c(s, a_U^*) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a_U^*) V(s') + \beta(\sigma) \Phi_{\text{spec}}(s').
\end{equation}
Subtracting $\mathcal{T}_{\text{SL}} U(s) = c(s, a_U^*) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a_U^*) U(s') + \beta(\sigma) \Phi_{\text{spec}}(s')$ from both sides, the nominal cost term $c(s, a_U^*)$ and the state-dependent spectral penalty term $\beta(\sigma) \Phi_{\text{spec}}(s')$ cancel out identically:
\begin{align}
0 \le \mathcal{T}_{\text{SL}} V(s) - \mathcal{T}_{\text{SL}} U(s) &\le \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a_U^*) \left( V(s') - U(s') \right) \\
&\le \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a_U^*) \left| V(s') - U(s') \right| \\
&\le \gamma \max_{s'' \in \mathcal{S}} \left| V(s'') - U(s'') \right| \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a_U^*).
\end{align}
Since transition probabilities sum to unity ($\sum_{s'} \mathcal{P}(s' \mid s, a_U^*) = 1$):
\begin{equation}
\mathcal{T}_{\text{SL}} V(s) - \mathcal{T}_{\text{SL}} U(s) \le \gamma \|V - U\|_\infty.
\end{equation}
By exact symmetry, if $\mathcal{T}_{\text{SL}} U(s) \ge \mathcal{T}_{\text{SL}} V(s)$, evaluating sub-optimality using action $a_V^*$ yields $\mathcal{T}_{\text{SL}} U(s) - \mathcal{T}_{\text{SL}} V(s) \le \gamma \|U - V\|_\infty$. Hence:
\begin{equation}
\left| \mathcal{T}_{\text{SL}} V(s) - \mathcal{T}_{\text{SL}} U(s) \right| \le \gamma \|V - U\|_\infty \quad \text{for all } s \in \mathcal{S}.
\end{equation}
Taking the supremum over all states $s \in \mathcal{S}$:
\begin{equation}
\|\mathcal{T}_{\text{SL}} V - \mathcal{T}_{\text{SL}} U\|_\infty \le \gamma \|V - U\|_\infty.
\end{equation}
Because $\gamma \in (0, 1)$, $\mathcal{T}_{\text{SL}}$ is a strict contraction mapping with Lipschitz modulus $\gamma$.

By the Banach Fixed-Point Theorem, $\mathcal{T}_{\text{SL}}$ possesses a unique fixed point $V_{\text{SL}}^* \in \mathcal{B}(\mathcal{S})$ satisfying $\mathcal{T}_{\text{SL}} V_{\text{SL}}^* = V_{\text{SL}}^*$. Furthermore, for any initial value function $V_0$, the value iteration sequence $V_{k+1} = \mathcal{T}_{\text{SL}} V_k$ converges linearly to $V_{\text{SL}}^*$ at geometric rate $\mathcal{O}(\gamma^k)$, with error bound:
\begin{equation}
\|V_k - V_{\text{SL}}^*\|_\infty \le \frac{\gamma^k}{1 - \gamma} \|V_1 - V_0\|_\infty.
\end{equation}
This concludes the proof.
\end{proof}

\subsection{Proof of Theorem~\ref{thm:trap_immunity} (Braess Trap Immunity)}
\label{subsec:proof_thm3}

\begin{proof}
Let $u \in V$ be the upstream origin node of an active Braess chord $e^* = (u \to v)$ satisfying $V_{uv} < 0$ and $k > 0$. The available action set at $u$ consists of traversing the candidate chord $a_{\text{chord}}$ and alternative base grid actions $a_{\text{bypass}} \in \mathcal{A}_{\text{base}}(u)$ leading to state $s_{\text{bypass}} \in V$ (e.g., right $(i+1, j)$ or down $(i, j+1)$).

Under the unique fixed-point value function $V_{\text{SL}}^*$, the greedy policy selects:
\begin{equation}
\pi_{\text{SL}}^*(u) = \arg\min_{a \in \mathcal{A}(u)} Q_{\text{SL}}^*(u, a),
\end{equation}
where the action-value function is given by:
\begin{equation}
Q_{\text{SL}}^*(u, a) = c(u, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid u, a) V_{\text{SL}}^*(s') + \beta(\sigma) \Phi_{\text{spec}}(s').
\end{equation}
To ensure that the optimal policy strictly avoids the Braess chord, it is necessary and sufficient that:
\begin{equation}
Q_{\text{SL}}^*(u, a_{\text{chord}}) > Q_{\text{SL}}^*(u, a_{\text{bypass}}).
\end{equation}
Assuming deterministic transitions from state $u$, we expand both sides:
\begin{equation}
\begin{split}
c(u, a_{\text{chord}}) &+ \gamma V_{\text{SL}}^*(v) + \beta(\sigma) \Phi_{\text{spec}}(v) \\
&> c(u, a_{\text{bypass}}) + \gamma V_{\text{SL}}^*(s_{\text{bypass}}) + \beta(\sigma) \Phi_{\text{spec}}(s_{\text{bypass}}).
\end{split}
\end{equation}
Rearranging terms to isolate the spectral penalty on the left-hand side:
\begin{equation}
\begin{split}
\beta(\sigma) \left[ \Phi_{\text{spec}}(v) - \Phi_{\text{spec}}(s_{\text{bypass}}) \right] &> c(u, a_{\text{bypass}}) - c(u, a_{\text{chord}}) \\
&\quad + \gamma \left[ V_{\text{SL}}^*(s_{\text{bypass}}) - V_{\text{SL}}^*(v) \right].
\end{split}
\end{equation}
By definition of the Spectral Congestion Divergence Potential, $\Phi_{\text{spec}} = \mathcal{G}_{\text{out}} |B \Delta \vec{\ell}|$. Because the chord concentrates background flow into node $v$, node divergence is maximal at $v$. By the non-negativity and strictly diagonally dominant properties of the regularized Green's operator $\mathcal{G}_{\text{out}} = (I - P + \eta I)^{-1}$ (Lemma~\ref{lem:green_norm}), the potential at the bottleneck sink strictly exceeds the potential at the bypass node:
\begin{equation}
\Delta \Phi_{\text{spec}} \equiv \Phi_{\text{spec}}(v) - \Phi_{\text{spec}}(s_{\text{bypass}}) > 0.
\end{equation}
Recall that the adaptive penalty weight is modulated by network spectral expansion:
\begin{equation}
\beta(\sigma) = \beta_0 (1 + \sigma(P)) \cdot f_{\text{load}}(\sigma),
\end{equation}
where $\sigma(P) = |\lambda_2(P)|$ is the Second Largest Eigenvalue Modulus (SLEM), and $f_{\text{load}}(\sigma) \ge 1$ under the congested regime $\sigma \ge \sigma_0$. Thus, $\beta(\sigma) \ge \beta_0 (1 + \sigma(P))$.

Substituting this lower bound into the inequality:
\begin{equation}
\begin{split}
\beta_0 (1 + \sigma(P)) \Delta \Phi_{\text{spec}} &> c(u, a_{\text{bypass}}) - c(u, a_{\text{chord}}) \\
&\quad + \gamma \left[ V_{\text{SL}}^*(s_{\text{bypass}}) - V_{\text{SL}}^*(v) \right].
\end{split}
\end{equation}
Dividing both sides by the strictly positive quantity $(1 + \sigma(P)) \Delta \Phi_{\text{spec}}$ yields:
\begin{equation}
\beta_0 \ge \frac{c(u, a_{\text{bypass}}) - c(u, a_{\text{chord}}) + \gamma \left( V_{\text{SL}}^*(s_{\text{bypass}}) - V_{\text{SL}}^*(v) \right)}{(1 + \sigma(P)) \left( \Phi_{\text{spec}}(v) - \Phi_{\text{spec}}(s_{\text{bypass}}) \right)}.
\end{equation}
When $\beta_0$ satisfies this bound, $Q_{\text{SL}}^*(u, a_{\text{chord}}) > Q_{\text{SL}}^*(u, a_{\text{bypass}})$ holds strictly, implying that $\pi_{\text{SL}}^*(u) \ne a_{\text{chord}}$. Consequently, the agent is guaranteed complete immunity from traversing the congested Braess bottleneck.
\end{proof}

\subsection{Proof of Theorem~\ref{thm:asymptotic_divergence} (Asymptotic Performance Divergence)}
\label{subsec:proof_thm4}

\begin{proof}
The proof decomposes the cumulative performance gap $T_{\text{PS}} - T_{\text{SL-PS}}$ along two orthogonal asymptotic regimes: the saturated congestion limit ($q \to \infty$) and the infinite topological network limit ($m + n \to \infty$).

\paragraph{Part 1: Saturated Traffic Limit ($q \to \infty$ on Fixed Grid).}
Consider a single active Braess chord $e^* = (u \to v)$ satisfying $V_{uv}(q) < 0$ and $k > 0$. By Lemma~\ref{lem:scale_invariance}, the electrical voltage drop across the chord endpoints satisfies:
\begin{equation}
V_{uv}(q) = q \cdot v_0, \quad \text{where } v_0 \equiv (e_s - e_t)^T L^+ (e_u - e_v) < 0.
\end{equation}
As $q \to \infty$, $V_{uv}(q) \to -\infty$ strictly proportional to $q$. Under Wardrop User Equilibrium (minimizing the Beckmann potential~\eqref{eq:beckmann}), the Karush-Kuhn-Tucker (KKT) first-order optimality condition for the chord equilibrium flow $z^*(q)$ evaluates to:
\begin{equation}
\ell^*(z^*) - V_{uv}(q) \le 0 \implies c z^* + d - q \cdot v_0 = 0.
\end{equation}
With nominal chord latency parameters $c \ge 0, d \ge 0$, the aggregate traffic flow traversing the chord scales as:
\begin{equation}
z^*(q) = \frac{-v_0 \cdot q - d}{a_{\text{eff}} + c} = \Theta(q).
\end{equation}
Because the chord channels macroscopic flow $z^*(q) = \Theta(q)$ into the downstream bottleneck corridor, there exists at least one base edge $e_{\text{neck}} \in E_0$ adjacent to sink $v$ carrying flow $f_{e_{\text{neck}}} \ge \alpha_0 z^*(q)$ for a fixed topological fraction $\alpha_0 > 0$. The physical traversal latency on this bottleneck edge evaluates to:
\begin{equation}
\ell(f_{e_{\text{neck}}}) = a f_{e_{\text{neck}}} + b \ge a \alpha_0 z^*(q) + b = \Omega(q).
\end{equation}
Under standard Prioritized Sweeping (PS) with backup budget $K = \mathcal{O}(1)$, the agent observes only the nominal cost $c(u, a_{\text{chord}}) = d \approx 0$ at origin state $u$. Because budget $K$ is insufficient to propagate downstream congestion back across the grid, PS greedily selects $\pi_{\text{PS}}(u) = a_{\text{chord}}$, entering the bottleneck corridor and suffering traversal latency:
\begin{equation}
T_{\text{PS}} \ge \ell(f_{e_{\text{neck}}}) = \Omega(q).
\end{equation}
In contrast, by Theorem~\ref{thm:trap_immunity}, the SL-PS agent evaluates $\beta(\sigma) \Phi_{\text{spec}} = \Theta(q)$ and strictly selects the alternative action $\pi_{\text{SL}}^*(u) = a_{\text{bypass}}$. Because background traffic has deserted the bypass corridors in favor of the shortcut (the classic Braess redistribution), the flow on the bypass corridor is strictly bounded: $f_{e_{\text{bypass}}} \le f_{\text{base}, e} = \mathcal{O}(1)$. Hence, travel time along the bypass path satisfies $T_{\text{SL-PS}} \le C_{\text{bypass}} = \mathcal{O}(1)$. Consequently, for any single Braess encounter:
\begin{equation}
\Delta T_{\text{single}} = T_{\text{PS}} - T_{\text{SL-PS}} \ge \Omega(q) - \mathcal{O}(1) = \Omega(q).
\end{equation}

\paragraph{Part 2: Infinite Topological Network Limit ($m + n \to \infty$).}
On grid $G_{m,n}$, the minimum topological path length between origin $(0, 0)$ and destination $(m, n)$ is $L_{\min} = m + n$. Along any realized navigation trajectory of length $T_{\text{steps}} \ge m + n$:
\begin{enumerate}
    \item At each decision step $t$, candidate chords emerge independently with probability $p_{\text{chord}} > 0$.
    \item On rectangular grids of fixed aspect ratio $n : m$, Lu \& Miller~\cite{lu2026braess} proved that the spatial density of Braess-capable chords ($V_{uv} < 0, k > 0$) is bounded below by a strictly positive constant $\rho_{\text{braess}} > 0$.
    \item Therefore, the total number of Braess chords emerging directly in the forward spatial neighborhood of the agent is a binomial random variable with expectation:
    \begin{equation}
    \mathbb{E}[N_{\text{traps}}] = p_{\text{chord}} \cdot \rho_{\text{braess}} \cdot (m + n) = \Theta(m + n).
    \end{equation}
    \item Because the local backup budget satisfies $K = o(m+n)$, the spatial radius of Bellman backups $\mathcal{R}_{\text{backup}} \le K$ is asymptotically negligible compared to the graph diameter $\operatorname{diam}(G) = \Theta(m+n)$. At each Braess encounter, Standard-PS suffers a strictly positive trap probability $P_{\text{trap}} \ge p_0 > 0$ (empirically $p_0 = 0.50$ in Table~\ref{tab:results}).
    \item By linearity of expectation, the expected number of Braess traps exploited by Standard-PS scales as:
    \begin{equation}
    \mathbb{E}[M_{\text{trapped}}] = p_0 \cdot \mathbb{E}[N_{\text{traps}}] = \Omega(m + n).
    \end{equation}
    Conversely, by Theorem~\ref{thm:trap_immunity}, SL-PS maintains an exact $0.0\%$ trap encounter rate across all steps.
\end{enumerate}

\paragraph{Part 3: Joint Asymptotic Limit.}
The total cumulative travel time advantage is the sum of delays across all encountered traps:
\begin{equation}
T_{\text{PS}} - T_{\text{SL-PS}} = \sum_{k=1}^{M_{\text{trapped}}} \Delta T_{\text{single}, k} \ge M_{\text{trapped}} \cdot \min_k \Delta T_{\text{single}, k}.
\end{equation}
Substituting the asymptotic lower bounds from Part 1 and Part 2:
\begin{equation}
T_{\text{PS}} - T_{\text{SL-PS}} \ge \Omega(m + n) \cdot \Omega(q) = \Omega\big(q \cdot (m + n)\big).
\end{equation}
Taking the joint limit as $(m + n) \to \infty$ and $q \to \infty$:
\begin{equation}
\lim_{\substack{m+n \to \infty \\ q \to \infty}} \left( T_{\text{PS}} - T_{\text{SL-PS}} \right) \ge \lim_{\substack{m+n \to \infty \\ q \to \infty}} C \cdot q \cdot (m + n) = +\infty,
\end{equation}
for some positive constant $C > 0$. This establishes the asymptotic divergence of the cumulative travel time gap and completes the proof.
\end{proof}

\section{Spectral Resolvent \& Green's Operator Analysis}
\label{sec:appendix_spectral}

In this section, we establish the mathematical properties of the policy-induced regularized Green's operators $\mathcal{G}_{\text{out}}$ and $\mathcal{G}_{\text{in}}$.

\begin{lemma}[Positivity and $L_\infty$ Resolvent Norm Bound]
\label{lem:green_norm}
Let $P \in \mathbb{R}^{|V| \times |V|}$ be a row-stochastic transition matrix ($\sum_j P_{ij} = 1, P_{ij} \ge 0$), and let $\eta > 0$ be the spectral regularization parameter. The out-Laplacian Green operator $\mathcal{G}_{\text{out}} = (I - P + \eta I)^{-1}$ satisfies:
\begin{enumerate}
    \item \textbf{Entrywise Non-Negativity}: $\mathcal{G}_{\text{out}, ij} \ge 0$ for all $i, j \in V$.
    \item \textbf{Uniform Operator Norm Bound}: $\|\mathcal{G}_{\text{out}}\|_\infty \le \frac{1}{\eta}$.
\end{enumerate}
\end{lemma}

\begin{proof}
Rewrite the operator as a scaled matrix resolvent:
\begin{equation}
\mathcal{G}_{\text{out}} = \left( (1 + \eta) I - P \right)^{-1} = \frac{1}{1 + \eta} \left( I - \frac{1}{1 + \eta} P \right)^{-1}.
\end{equation}
Define $\alpha = \frac{1}{1 + \eta}$. Since $\eta > 0$, we have $0 < \alpha < 1$. Because $P$ is row-stochastic, its induced infinity norm is $\|P\|_\infty = \max_i \sum_j |P_{ij}| = 1$. The spectral radius satisfies $\rho(\alpha P) \le \|\alpha P\|_\infty = \alpha < 1$.

Therefore, the Neumann series for $(I - \alpha P)^{-1}$ converges absolutely:
\begin{equation}
\mathcal{G}_{\text{out}} = \alpha \sum_{k=0}^\infty (\alpha P)^k = \sum_{k=0}^\infty \frac{1}{(1 + \eta)^{k+1}} P^k.
\end{equation}
Since $P_{ij} \ge 0$, every power $P^k$ has non-negative entries ($P^k_{ij} \ge 0$). Since $(1+\eta)^{-(k+1)} > 0$, every entry of $\mathcal{G}_{\text{out}}$ is a sum of non-negative real numbers, proving $\mathcal{G}_{\text{out}, ij} \ge 0$ for all $i, j$.

To bound the operator norm, apply the triangle inequality to the Neumann series:
\begin{align}
\|\mathcal{G}_{\text{out}}\|_\infty &\le \sum_{k=0}^\infty \frac{1}{(1 + \eta)^{k+1}} \|P\|_\infty^k = \frac{1}{1 + \eta} \sum_{k=0}^\infty \left( \frac{1}{1 + \eta} \right)^k \notag \\
&= \frac{1}{1 + \eta} \cdot \frac{1}{1 - \frac{1}{1 + \eta}} = \frac{1}{\eta}.
\end{align}
For our experimental configuration ($\eta = 0.1$), $\|\mathcal{G}_{\text{out}}\|_\infty \le 10.0$, guaranteeing that the diffused spectral potential remains strictly bounded for any finite network divergence.
\end{proof}

\begin{lemma}[Spectral Scale Invariance of Voltage Drop Sign]
\label{lem:scale_invariance}
Let $L^+$ be the Moore-Penrose pseudoinverse of the base grid Laplacian $L$. For any positive traffic demand $q > 0$, the sign of the electrical voltage drop across any chord $u \to v$ is strictly invariant to $q$:
\begin{equation}
\operatorname{sign}\left( V_{uv}(q) \right) = \operatorname{sign}\left( (e_s - e_t)^T L^+ (e_u - e_v) \right).
\end{equation}
\end{lemma}

\begin{proof}
Under total traffic injection $p = q (e_s - e_t)$, the electrical potential is $\phi(q) = q L^+ (e_s - e_t)$. The voltage drop across endpoints $u$ and $v$ is:
\begin{equation}
V_{uv}(q) = \phi_u(q) - \phi_v(q) = (e_u - e_v)^T \phi(q) = q \cdot \left[ (e_s - e_t)^T L^+ (e_u - e_v) \right].
\end{equation}
Because $q > 0$ is a strictly positive scalar, multiplying by $q$ preserves the mathematical sign:
\begin{align}
\operatorname{sign}\left( V_{uv}(q) \right) &= \operatorname{sign}(q) \cdot \operatorname{sign}\left( (e_s - e_t)^T L^+ (e_u - e_v) \right) \notag \\
&= \operatorname{sign}\left( (e_s - e_t)^T L^+ (e_u - e_v) \right).
\end{align}
Hence, whether a chord is Braess-capable ($V_{uv} < 0$) is an intrinsic topological property determined entirely by $L^+$ and the relative coordinate positions of $s, t, u, v$, completely independent of the empirical traffic volume $q$.
\end{proof}

\begin{lemma}[Spectral Stability and Resolvent Invariance under Rank-1 Chord Perturbation]
\label{lem:weyl_stability}
Let $P_0 \in \mathbb{R}^{|V| \times |V|}$ be the base nominal random-walk matrix of grid $G_0$, and let $P_t = P_0 + \Delta P$ denote the augmented transition matrix when an auxiliary chord $e^* = (u \to v)$ is added. Then:
\begin{enumerate}
    \item \textbf{Rank-1 Perturbation Bound}: $\Delta P$ is a rank-1 perturbation with spectral norm bounded by:
    \begin{equation}
    \|\Delta P\|_2 \le \frac{1}{\sqrt{d_{\text{out}}(u) (d_{\text{out}}(u) + 1)}},
    \end{equation}
    where $d_{\text{out}}(u) \ge 1$ is the nominal out-degree of node $u$.
    \item \textbf{SLEM Eigenvalue Stability (via Weyl's Theorem)}: The shift in the Second Largest Eigenvalue Modulus $\sigma(P) = |\lambda_2(P)|$ satisfies:
    \begin{equation}
    \left| \sigma(P_t) - \sigma(P_0) \right| \le \|\Delta P\|_2 \le \mathcal{O}\left( \frac{1}{|V|^{1/2}} \right).
    \end{equation}
    \item \textbf{Green's Resolvent Operator Invariance (via Sherman-Morrison)}: The difference between the augmented Green operator $\mathcal{G}_{\text{out}}^{(t)} = (I - P_t + \eta I)^{-1}$ and the precomputed base Green operator $\mathcal{G}_{\text{out}}^{(0)} = (I - P_0 + \eta I)^{-1}$ satisfies:
    \begin{equation}
    \|\mathcal{G}_{\text{out}}^{(t)} - \mathcal{G}_{\text{out}}^{(0)}\|_\infty \le \frac{\|\mathcal{G}_{\text{out}}^{(0)}\|_\infty^2 \|\Delta P\|_\infty}{1 - \|\mathcal{G}_{\text{out}}^{(0)}\|_\infty \|\Delta P\|_\infty} = \mathcal{O}\left( \frac{1}{\eta^2 d_{\text{out}}(u)} \right).
    \end{equation}
\end{enumerate}
Consequently, computing $\Phi_{\text{spec}}$ using the offline precomputed base Green operator $\mathcal{G}_{\text{out}}^{(0)}$ introduces at most an $\mathcal{O}(1/|V|)$ perturbation to the potential field, rigorously justifying offline precomputation for real-time online planning.
\end{lemma}

\begin{proof}
When an auxiliary directed chord $e^* = (u \to v)$ is added to $G_0$, only the out-neighborhood of node $u$ is modified. Let $d_0 = d_{\text{out}}(u)$ be the nominal out-degree at $u$, which increases to $d_0 + 1$. The $u$-th row of the nominal transition matrix, originally given by $P_0(u, \cdot) = \frac{1}{d_0} \sum_{w \in \mathcal{N}_{\text{out}}(u)} e_w^T$, transitions to:
\begin{equation}
P_t(u, \cdot) = \frac{1}{d_0 + 1} \left( \sum_{w \in \mathcal{N}_{\text{out}}(u)} e_w^T + e_v^T \right).
\end{equation}
All other rows $i \ne u$ remain strictly unchanged ($P_t(i, \cdot) = P_0(i, \cdot)$). Therefore, the perturbation matrix is zero everywhere except on row $u$:
\begin{align}
\Delta P &= P_t - P_0 = e_u \left( P_t(u, \cdot) - P_0(u, \cdot) \right) \notag \\
&= e_u \left( \frac{1}{d_0 + 1} e_v^T - \frac{1}{d_0 (d_0 + 1)} \sum_{w \in \mathcal{N}_{\text{out}}(u)} e_w^T \right).
\end{align}
This establishes that $\operatorname{rank}(\Delta P) = 1$. The Frobenius norm (which bounds the spectral norm $\|\cdot\|_2$) evaluates to:
\begin{align}
\|\Delta P\|_2^2 &\le \|\Delta P\|_F^2 = \left( \frac{1}{d_0 + 1} \right)^2 + d_0 \left( \frac{1}{d_0 (d_0 + 1)} \right)^2 \notag \\
&= \frac{1}{(d_0 + 1)^2} \left( 1 + \frac{1}{d_0} \right) = \frac{1}{d_0 (d_0 + 1)}.
\end{align}
Taking the square root yields $\|\Delta P\|_2 \le \frac{1}{\sqrt{d_0 (d_0 + 1)}} \le \frac{1}{d_0}$.

By Weyl's Perturbation Theorem~\cite{bhatia1997matrix, weyl1912asymptotische}, for any matrix perturbation $A + E$, the singular values and eigenvalues of the symmetric part satisfy $|\lambda_i(P_t) - \lambda_i(P_0)| \le \|\Delta P\|_2$. For a grid with $N = |V| = (m+1)(n+1)$ vertices, local node degree $d_0 \ge 1$ implies that the influence of a single row modification on the global spectrum is bounded by $\mathcal{O}(1/\sqrt{N})$.

Finally, by the resolvent identity and the Sherman-Morrison rank-1 update formula, defining $M_0 = (1 + \eta)I - P_0$:
\begin{equation}
\mathcal{G}_{\text{out}}^{(t)} - \mathcal{G}_{\text{out}}^{(0)} = \left( M_0 - \Delta P \right)^{-1} - M_0^{-1} = M_0^{-1} \Delta P \left( I - M_0^{-1} \Delta P \right)^{-1} M_0^{-1}.
\end{equation}
Taking the induced infinity norm on both sides and using Lemma~\ref{lem:green_norm} ($\|M_0^{-1}\|_\infty = \|\mathcal{G}_{\text{out}}^{(0)}\|_\infty \le \frac{1}{\eta}$):
\begin{equation}
\|\mathcal{G}_{\text{out}}^{(t)} - \mathcal{G}_{\text{out}}^{(0)}\|_\infty \le \frac{\|\mathcal{G}_{\text{out}}^{(0)}\|_\infty^2 \|\Delta P\|_\infty}{1 - \|\mathcal{G}_{\text{out}}^{(0)}\|_\infty \|\Delta P\|_\infty}.
\end{equation}
Since $\|\Delta P\|_\infty = \sum_j |\Delta P_{uj}| = \frac{2}{d_0 + 1}$, this difference is bounded by $\mathcal{O}\left( \frac{1}{\eta^2 d_0} \right)$ localized strictly to the upstream neighborhood of $u$. The global wavefront diffusion $\mathcal{G}_{\text{out}} |B \Delta \vec{\ell}|$ remains faithful to the true potential field, rigorously confirming the stability of offline precomputation.
\end{proof}

\section{Computational Complexity \& Priority Queue Analysis}
\label{sec:appendix_complexity}

\begin{proposition}[Per-Step Online Computational Complexity]
\label{prop:complexity}
Let $G = (V, E)$ be a directed grid with maximum vertex out-degree $d = \max_{s} |\mathcal{A}(s)| \le 3$, and let $K$ denote the Prioritized Sweeping backup budget. Under precomputed Green operators $\mathcal{G}_{\text{out}}$ and $\mathcal{G}_{\text{in}}$, the online time complexity of SL-PS per decision step is:
\begin{equation}
\mathcal{T}_{\text{online}} = \mathcal{O}\left( |E_0| + |V| + K \cdot d \log |V| \right) = \mathcal{O}(|V| + K \log |V|).
\end{equation}
\end{proposition}

\begin{proof}
We analyze each phase of Algorithm~1:
\begin{enumerate}
    \item \textbf{Flow Divergence Calculation}: Computing $\Delta \vec{\ell} = a (f_{\text{curr}} - f_{\text{base}})$ and the divergence vector $\xi_{\text{div}} = |B \Delta \vec{\ell}|$ requires a single sparse matrix-vector multiplication with the incidence matrix $B$. Since each edge has exactly two non-zero entries in $B$, this takes $\mathcal{O}(|E_0|)$ operations.
    \item \textbf{Global Green Diffusion}: Evaluating $\Phi_{\text{spec}} = \mathcal{G}_{\text{out}} \xi_{\text{div}}$ requires a matrix-vector product. Because $\mathcal{G}_{\text{out}}$ is precomputed offline, this dense operation requires $\mathcal{O}(|V|^2)$ operations, which reduces to $\mathcal{O}(|V| \cdot d)$ when solving the linear system $(I - P + \eta I) \Phi = \xi_{\text{div}}$ via sparse preconditioned conjugate gradient.
    \item \textbf{Priority Queue Construction}: Computing initial priorities $p(s) = \xi(s) + \beta f_{\text{in}}(s)$ and inserting non-zero states into the binary min-heap requires $\mathcal{O}(|V| \log |V|)$ in the worst case, or $\mathcal{O}(|V|)$ via linear-time heapify.
    \item \textbf{Budgeted Value Backups}: At each of the $K$ iterations, extracting the top state takes $\mathcal{O}(\log |V|)$, evaluating the Bellman backup takes $\mathcal{O}(d)$, and pushing predecessor updates takes $\mathcal{O}(d \log |V|)$. Total backup time is $\mathcal{O}(K \cdot d \log |V|)$.
\end{enumerate}
Summing these components, total online execution time is $\mathcal{O}(|V| + K \log |V|)$, which scales gracefully to large-scale grids and remains strictly decoupled from episode length $T$.
\end{proof}
